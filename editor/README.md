# Эдитор промптов и инструментов

## Что это?

Эдитор — веб-интерфейс для редактирования промптов агентов и тестирования инструментов без изменения кода напрямую.

## Возможности

- ✏️ **Редактирование промптов агентов** — изменение промптов в файлах `app/agents/*_stage.py`
- 🔄 **Редактирование промпта роутера** — изменение промпта в `app/agents/router_stage.py`
- 🧪 **Тестирование инструментов** — выполнение инструментов с заданными параметрами

## Как работает?

Эдитор работает через Flask веб-сервер и состоит из:

1. **Парсер** (`parser.py`) — извлекает промпты из файлов проекта
2. **Обновлятор** (`updater.py`) — сохраняет изменения промптов обратно в файлы
3. **Помощник инструментов** (`tools_helper.py`) — загружает и выполняет инструменты
4. **Веб-интерфейс** (`templates/index.html`) — пользовательский интерфейс

Эдитор автоматически подключается к:
- **Реестру агентов** (`app/agents/registry.py`) — для получения списка всех агентов
- **Реестру инструментов** (`app/tools/registry.py`) — для получения списка всех инструментов

## Запуск

```bash
python run_editor.py
```

Эдитор будет доступен по адресу: `http://localhost:5000`

## Важно

- **Изменения применяются сразу** — промпты обновляются в файлах без перезапуска сервера
- **Агенты и инструменты берутся из реестров** — убедитесь, что новые агенты/инструменты зарегистрированы в соответствующих реестрах
- **Резервное копирование** — перед массовыми изменениями рекомендуется сделать бэкап файлов

## Структура файлов

```
editor/
├── app.py              # Flask приложение с API endpoints
├── parser.py           # Парсер промптов из файлов
├── updater.py          # Обновлятор промптов в файлах
├── tools_helper.py     # Помощник для работы с инструментами
├── templates/
│   └── index.html      # Веб-интерфейс
└── README.md           # Этот файл
```

## Подключение к проекту

Эдитор автоматически подключается к проекту через:

1. **Реестр агентов** (`app/agents/registry.py`)
   - Эдитор читает список агентов из реестра
   - Для каждого агента загружает промпт из соответствующего файла

2. **Реестр инструментов** (`app/tools/registry.py`)
   - Эдитор загружает все инструменты из реестра
   - Позволяет тестировать инструменты с заданными параметрами

3. **Файлы агентов** (`app/agents/*_stage.py`)
   - Эдитор читает и обновляет промпты напрямую в файлах агентов

4. **Промпт роутера** (`app/agents/router_stage.py`)
   - Эдитор читает и обновляет промпт роутера

**Никаких дополнительных настроек не требуется** — просто запустите эдитор и он автоматически подключится к проекту.
